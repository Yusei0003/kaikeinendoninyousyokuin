# 会計年度任用職員 一元管理システム

会計年度任用職員の **任用・人事評価・採用試験** を1つの画面でまとめて管理する、ブラウザだけで動くツールです。
日直勤務表アプリと同じく、サーバー不要・外部通信なしで、LGWAN（LG回線）端末でそのまま使えます。データはブラウザの localStorage に保存し、**バックアップファイル（.json）** で保全・引継ぎします。

## 起動方法

`index.html` をブラウザ（Edge／Chrome）で開くだけです（ダブルクリックでOK）。インストールやネット接続は不要です。
フォルダごと共有フォルダ等に置いて使えます（`vendor/`・`js/` フォルダも一緒に置いてください）。

## できること

| タブ | 内容 |
| --- | --- |
| ホーム | 在職者数、任用予定、要確認の任用、評価未入力、実施中の試験、任期満了が近い職員 |
| 職員台帳 | 職員の基本情報。「詳細」で任用履歴・人事評価・応募歴を一覧（一元管理） |
| 任用管理 | 任期・所属・区分（フル／パート）・勤務時間・報酬の登録、自動点検、任期更新、次年度の任用案の一括作成、任期等の明示書の印刷、Excel書出し |
| 人事評価 | 年度ごとの評価項目・総合評価・所見（再度の任用の可否）の入力。未入力者の強調表示 |
| 採用試験 | 競争試験／選考の登録、応募者（Excel取込可）、選考区分ごとの得点入力・合計・順位、合格者を台帳・任用へそのまま登録 |
| Excel取込 | 既存のExcel台帳（職員・任用・評価）を読み込み。見出し行の自動検出、列名の揺れ吸収、和暦日付対応、取込前の確認 |
| 根拠法令 | 国／市のレベル別に根拠法令を表示。原文の条文を貼り付けて「原文確認済み」として保存 |
| 設定・バックアップ | 判定に使う値の変更、バックアップ保存・復元、全データのExcel書出し、データ消去 |

### 任用の自動点検

| 点検内容 | 根拠 |
| --- | --- |
| 任期が採用の日の属する会計年度の末日（3月31日）を超えていないか | 【国】地方公務員法第22条の2 |
| フルタイムは常勤と同じ週勤務時間、パートタイムは常勤より短いか | 【国】地方公務員法第22条の2第1項各号 |
| 任期の更新が同一会計年度内か | 【国】地方公務員法第22条の2 |
| 同じ職員の任期が重なっていないか | （データの整合性） |
| 公募によらない再度の任用が上限回数を超えていないか | 市の運用方針（設定値。空欄なら判定しない） |
| 報酬額の入力漏れ | 【市】陸前高田市会計年度任用職員の給与等に関する条例・規則 |

エラーがある任用は登録できません（取消扱いを除く）。要確認（警告）は内容を確認すれば登録できます。

### 次年度の任用案

「任用管理」→「次年度の任用案を作成」で、対象年度の任用と人事評価から翌年度の「再度の任用」案を一括作成します。
以下に当てはまる職員は推薦から外れ、理由が表示されます：評価未入力／総合評価が推薦基準外／所見が「不可」「要検討」／再度の任用の上限超過（公募が必要）／翌年度の任用が登録済み。

## 根拠法令について（重要）

| レベル | 法令 | 状態 |
| --- | --- | --- |
| 国 | 地方公務員法 第22条の2（会計年度任用職員の採用の方法等） | **原文未確認** |
| 市 | 陸前高田市会計年度任用職員の給与等に関する条例 | **原文未確認** |
| 市 | 陸前高田市会計年度任用職員の給与等に関する規則 | **原文未確認** |

開発環境からは e-Gov法令検索・陸前高田市例規集に接続できなかったため、条文の原文は取得できていません。
地方公務員法第22条の2の内容（採用は競争試験又は選考による／任期は会計年度の末日までの範囲内／勤務実績を考慮した任期の更新／フル・パートの区分）は Web 検索結果の要約で確認したものです。**項番号・文言は原文で確認してください。**
市の条例・規則は条例番号・条文とも未確認です。

このため、判定に使う値（常勤の週勤務時間、再度の任用の上限回数、条件付採用期間など）はすべて「設定」で変更できるようにしています。
「根拠法令」タブに原文を貼り付けて確認日を入れると「原文確認済み」と表示されます。

## バックアップと引継ぎ

- データはその端末のブラウザ内だけに保存されます。**作業の終わりに「設定・バックアップ」→「バックアップを保存」** を押し、ファイルを共有フォルダ等に保管してください。前回から一定日数（既定7日）が経つと画面上部に警告が出ます。
- 別の端末・後任者へは、バックアップファイルを「バックアップから復元」で読み込めばそのまま引き継げます（復元すると、その端末のデータは置き換わります）。
- 引継ぎ後、前任者の端末は「この端末のデータをすべて消去」で消去してください。
- 個人情報を扱うため、共用端末では使用しないでください。

## Excel取込のコツ

- 「取込用のひな形をダウンロード」で列見出しの例を確認できます。見出しは多少違っても自動で対応付けます（例：「任期（自）」「任用開始日」「開始日」はどれも任期の開始日として読み込み）。
- 日付は `2026/4/1`、`R8.4.1`、`令和8年4月1日`、Excelの日付セルのいずれも読み込めます。
- 職員は職員番号 → 氏名の順で照合します。任用・評価の取込時、台帳にない職員は自動追加できます。
- 同じ職員・同じ任期の任用は重複登録されません。評価は同じ職員・同じ年度なら上書きします。

```
js/core.js    判定・計算ロジック（画面から独立。Node.jsでテスト可能）
js/app.js     画面処理
style.css     スタイル
vendor/       同梱ライブラリ（SheetJS）
tests/        core.js の単体テスト
```

テスト：`node --test tests/`
