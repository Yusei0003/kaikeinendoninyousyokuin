# 会計年度任用職員 一元管理システム

会計年度任用職員の **任用・人事評価・採用試験** を1つの画面でまとめて管理する、ブラウザだけで動くツールです。
日直勤務表アプリと同じく、サーバー不要・外部通信なしで、LGWAN（LG回線）端末でそのまま使えます。データはブラウザの localStorage に保存し、**バックアップファイル（.json）** で保全・引継ぎします。

## 起動方法

`index.html` をブラウザ（Edge／Chrome）で開くだけです（ダブルクリックでOK）。インストールやネット接続は不要です。
フォルダごと共有フォルダ等に置いて使えます（`vendor/`・`js/` フォルダも一緒に置いてください）。

## できること（タブの順）

| タブ | 内容 |
| --- | --- |
| 職員台帳 | 職員の一覧（対象年度に任用のある職員に絞り込み可）。氏名を押すと**経歴**（働き始め・勤続・年度ごとの所属/職名と変更点・人事評価・応募歴） |
| **任用一覧**（起動時の画面） | **総務課「任用一覧」と同じ項目**で年度ごとの任用を管理。市マニュアルによる自動判定と点検、任期更新、明示書の印刷、任用一覧と同じ様式でのExcel書出し |
| 年目・任用意向 | 3年周期の何年目か・公募年度・勤続を確認し、**再度の任用の可否**と**本人の希望**をその場で入力。翌年度の見込み（残る／公募／残らない／未定）を表示 |
| 公募職種 | 残らない職員・3年目の職員の職（自動）と、新規・増員の職（手入力）を整理し、職ごとに公募する／しないを決定。所属・業務内容・区分ごとの募集人数をまとめ、採用試験を作成 |
| 再度の任用 | 可否「可」・本人「希望する」・4年目にならない職員の一覧。チェックして翌年度に一括登録、Excel出力 |
| 退職・残留 | 翌年度に残る人・残らない人の一覧と件数。任期満了・自己都合などの退職登録（年度途中は任期を短縮）と退職手続きのチェック（申送事項「退職処理」） |
| 年度替わり事務 | 総務課（職員係）が出す通知ごと（任用希望調査／再度の任用に係る確認／募集方法／再度の任用／選考方法／年度切替の事務手続き）に、作成→決裁→通知→回答の受付→督促→取りまとめの進み具合と、課ごとの回答の状況（未・済・該当なし。退職者は資格確認証・タイムカード・名札ケース）を記録。**年度を開くと自動で作成**。日付は令和8年度任用の総務課長通知の日程をもとに土日・祝日・年末年始を避けて計算（変更可）。次にやる作業は「状況・手続き」にも表示 |
| 人事評価 | 年度ごとの評価項目・総合評価・所見の入力 |
| 採用試験 | 競争試験／選考の登録、応募者、得点・順位、合格者の提出書類、合格者を台帳・任用へ登録 |
| 状況・手続き | 年度別の状況、今後90日の手続き（退手・共済の切替など）、来年4月に公募が必要な職員、年間スケジュール |
| Excel取込 | **人事システムの職員名簿**（採用時・初回利用時）、**人事システムの任用**（在職期間・任期の継続の確認）、**年数確認データ**（3年周期の何年目か）、**過去の任用一覧**をそのまま取込。ファイルの種類は見出しから自動判別し、必要な列を画面に明記 |
| 根拠法令 | 国／市のレベル別に根拠法令・資料を表示し、原文を貼り付けて保存 |
| 設定・バックアップ | 判定に使う値の変更、バックアップ保存・復元、全データのExcel書出し |

### 年間の流れ（申送事項・市マニュアル第Ⅷ章）

1. **11月**：「年目・任用意向」で3年目（公募の対象）を確認 → 「公募職種」で公募する職種・人数を決定
2. **1月**：「年目・任用意向」で再度の任用の可否・本人の希望を入力（再度の任用に関する通知） → 「採用試験」で公募・選考
3. **3月**：「再度の任用」で翌年度に一括登録、合格者を任用登録 → 「任用一覧（様式）で書き出す」で任用一覧を作成／「退職・残留」で任期満了退職者を確認
4. **4月**：退職者の喪失手続き・新規採用者の取得手続き（「退職・残留」の手続きチェック）

### 任用の自動点検

| 点検内容 | 根拠 |
| --- | --- |
| 任期が採用の日の属する会計年度の末日（3月31日）を超えていないか | 【国】地方公務員法第22条の2 |
| フルは週38.75時間、パートは週38.75時間未満か | 【国】地方公務員法第22条の2第1項各号／【市】市マニュアル第Ⅰ章2 |
| 週35時間以上のパート（勤務時間設定の考え方の説明が必要） | 【市】市マニュアル第Ⅱ章2 |
| 給料・報酬額が算定式どおりか（月額＝基礎額×週時間/38.75、日額＝基礎額/21、時間額＝基礎額/162.75、1円未満切捨て） | 【市】市マニュアル第Ⅲ章1・2 |
| 支給日（フル・月額パート＝毎月21日、日額・時間額パート＝翌月21日） | 【市】市マニュアル第Ⅲ章3 |
| 期末手当の有無（任用期間6か月以上かつ週15時間30分以上） | 【市】市マニュアル第Ⅳ章10 |
| 年休の付与日数（週の勤務日数（または任用期間の勤務日数）×継続勤務年数の表、フル・月額パートは週5日。週4日以内でも週29時間以上なら「5日以上」の区分。継続勤務年数の1年未満の端数は1年とみなす。任期が短くても既定は付与し、任用ごとに「付与しない」を選べる。時間額パートは既定で付与しない（必要な人は日数を手入力）。繰越分は含めない） | 【市】市マニュアル第Ⅴ章1／年次休暇の規定（条例・規則名は未確認） |
| 社会保険（フル・週29時間以上＝共済(短期)、フル12月経過＝共済）、雇保/退手（週20時間以上かつ31日以上＝雇用保険、フル6月経過＝退手） | 【市】市マニュアル第Ⅶ章1・2 |
| 公募によらない再度の任用（毎年4月の更新）は連続2回まで。採用月にかかわらず採用した年度を1年目と数え、4年目の4月は公募（例：R5.11採用・R5.4採用とも R5①・R6②・R7③ → R8.4に公募） | 【市】市マニュアル第Ⅷ章2 |
| 保育士の特定登録取消者管理システムの確認 | 任用一覧の確認項目 |
| 同じ職員の任期の重複／給料・報酬額の入力漏れ | データの整合性 |

エラーがある任用は登録できません（取消扱いを除く）。要確認（警告）は内容を確認すれば登録できます。

**勤続と3年周期は別々に数えます**
- **3年周期の年目（公募の判断）**：採用月にかかわらず採用した年度を1年目と数え、公募で採用すると1年目に戻ります。4年目の4月は公募です（「年目」「公募」列）。
- **勤続（継続勤務）**：公募で採用し直しても、任用が切れ目なく続いていれば通算します（「勤続」列）。年休の継続勤務年数、フルタイムの退手（6月経過）・共済（12月経過）の切替に使います。任用が途切れた場合は数え直します。
- 勤続の起算日は、①任用の「勤続開始日」の入力 → ②任用履歴を切れ目なくさかのぼった最初の任用 → ③履歴がそれ以上ない場合は**職員名簿の採用日（最初に採用された日）** → ④採用日もなければ3年周期の年目から推定、の順で決めます。採用後に途切れた期間があり、その履歴を取り込んでいない場合は「勤続開始日」を入力してください。
- フルタイムの退手・共済の切替は、フルタイムで切れ目なく続いた期間で判定します（名簿の採用日はフルタイムかどうか分からないため使いません。必要なら「フルタイム継続開始日」を入力）。

任用の入力画面には、市マニュアルによる判定（報酬額・支給日・期末手当・社会保険・雇保/退手・切替時期・健康診断の対象）が表示され、「判定結果を入力欄に反映」で入力できます。

### 再度の任用の判定

「再度の任用」タブでは、次のすべてを満たす職員を対象として一覧にします：再度の任用の可否が「可」／本人が「希望する」／翌年度が4年目にならない（公募によらない再度の任用は連続2回まで）／退職登録がない／翌年度の任用が未登録。人事評価の評語が未入力の場合は注意書きを表示します。

### 年度ごとの管理
- 画面上部の年度ボタン（R5年度・R6年度…、人数つき）で対象年度を切り替えます。任用管理・人事評価・職員台帳・書出しはすべて選んだ年度が対象です。
- ホームの「年度別の状況」で、年度ごとの任用人数・区分・公募/再度の任用・翌年度への継続・評価の入力状況を比べられます。

### 経歴（氏名を押すと表示）
- 働き始め（初回任用日）、勤続（切れ目なく継続している開始日・継続勤務年数）、現在の所属・職名、3年周期の年目と公募年度、所属・職名の変更回数。
- 年度ごとの任用を新しい順に表示し、前年度からの変更点（所属変更・職名変更・区分変更・時間変更・報酬変更・途切れ・公募・任期更新）を色分けして示します。
- 人事評価・採用試験の応募歴も同じ画面で確認でき、「経歴をExcelに書き出す」で1人分の経歴を出力できます。

## バックアップと引継ぎ

- データはその端末のブラウザ内だけに保存されます。**作業の終わりに「設定・バックアップ」→「バックアップを保存」** を押し、ファイルを共有フォルダ等に保管してください。前回から一定日数（既定7日）が経つと画面上部に警告が出ます。
- 別の端末・後任者へは、バックアップファイルを「バックアップから復元」で読み込めばそのまま引き継げます（復元すると、その端末のデータは置き換わります）。
- 引継ぎ後、前任者の端末は「この端末のデータをすべて消去」で消去してください。
- 個人情報を扱うため、共用端末では使用しないでください。

## Excel取込のコツ

### 取り込めるファイルと必要な列

| ファイル | 出力元・保存場所 | 必要な列 | あれば取り込む列 |
| --- | --- | --- | --- |
| 職員名簿 | 人事システムの職員名簿 | 番号、区分名（C列）、氏名、採用日（または生年月日） | ﾌﾘｶﾞﾅ、性別、生年月日、退職日、職種、所属CD、所属名、職名、係名、級、号、在職、郵便番号、住所、住所方書、電話、携帯、Mail、緊急時連絡先 |
| 任用（人事システム） | 人事sys →「ﾆ 任用」→ 何も入力せずに「検索」で出力 | 職員番号、氏名、区分、開始日、終了日（空欄＝継続中） | 退職事由、備考 |
| 年数確認データ | `S:\1100-総務課\02-職員係\100_会計年度任用職員\020_任用退職・採用試験・人事評価\020_再度の任用` フォルダの情報 | 番号、会計年度任用年数、氏名 | 身分、所属名、職名 |
| 任用一覧 | 総務課の任用一覧（年度ごと） | 氏名、任用期間（または区分） | 任用一覧の全27列 |

初めて使うときは、①過去の任用一覧（古い年度から）→ ②職員名簿 → ③任用（人事システム）→ ④年数確認データ の順がおすすめです。

### 任用（人事システム）

- 1行＝1つの在職期間です（区分が変わると別の行）。職員ごとに在職期間を置き換えます（任用一覧の任用は変更しません）。見出しのない列（「変・複」など）は読みません。
- **任期が継続しているか**：前の期間の終了日の翌日に次の期間が始まっていれば「切れ目なし」、空いていれば「○日空き（途切れ）」と経歴に表示し、取込後にも一覧にします。
- 勤続（年休の継続勤務年数）は、人事システムの在職期間を切れ目なくさかのぼった開始日から数えます（区分がフル→パート→フルと変わっても通算）。フルタイムの退手・共済の切替は、フルの期間だけで判定します。
- 任用一覧の任用の開始日が、人事システムの在職期間のどれにも含まれない場合は、点検で要確認を出します。

### 年数確認データ

- 「会計年度任用年数」を**何年度の年目として取り込むか、取込時の確認画面で選びます**（既定は画面上部で選んでいる年度。今年度・翌年度などから選択）。
- その年度の任用があれば任用の「会計年度（何年目）」にも入れ、年目・任用意向／公募職種／再度の任用の判定に使います。

### 職員名簿（人事システムの出力）

- 採用があったとき、また初めて使うときに、人事システムの職員名簿をそのまま取り込みます。ファイルを選ぶと見出しから自動で判別します。
- 読み込む項目：番号・氏名・ﾌﾘｶﾞﾅ・性別（1＝男性、0/2＝女性）・生年月日・採用日・退職日・区分名・職種・所属CD・所属名・職名・係名・級・号・在職・郵便番号・住所（＋方書）・電話・携帯・Mail・緊急時連絡先。
- **PASS・内線等・財務・労務・経歴などの列は読み込みません。**
- **C列（区分名）が「会計年度任用職員」の行だけ**を取り込みます。正職員などの行は内容（氏名を含む）を読まずに除外し、件数だけ表示します。このアプリは会計年度任用職員だけを扱います。
- 既存の職員とは、職員番号 → 氏名と生年月日 の順で照合し、名簿の値で上書きします。任用一覧から先に取り込んだ職員（番号なし）にも番号や性別・生年月日が入ります。
- 名簿の採用日を含む任用がない職員（対象年度以降の採用日）は、取込後に「任用を登録」から登録できます。所属・職名・任用期間（採用日〜年度末）は名簿の値で入力済みです。今後90日以内の採用日の職員は「状況・手続き」にも表示します。
- **初めて使うとき**は、①過去の任用一覧を古い年度から取込 → ②職員名簿を取込 の順がおすすめです（逆の順でも照合されます）。

### 任用一覧（総務課の様式）

- 「Excel取込」→「任用一覧（総務課の様式）」を選び、年度ごとの任用一覧をそのまま読み込みます。**古い年度から順に**取り込むと、年目・再度の任用の回数・フルタイムの継続期間（退手・共済の切替時期）が正しく計算されます。
- 年度は見出し「R8.4.1 社会保険」から判定します。任用期間が空欄の行はその年度の1年間として登録し、「確認が必要な行」として表示します。
- 「会計年度」列は、採用した年度を1年目とした年目（1〜3）として扱い、2以上は「再度の任用」として登録します。任用一覧の「公募」列とホームの「来年4月に公募が必要な職員」に、公募が必要になる年度を表示します。
- 「給料・報酬」の右隣の見出しなし列を金額として読み込みます。「勤務時間/週」が「随時」などの文字の行は、その文字を記録します。
- 切替時期の列（「4/1」など）は月/日の文字として読み込みます。
- 同じ職員・同じ開始日の任用はExcelの内容で上書きするため、同じファイルを何度取り込んでも二重登録されません。
- 「任用管理」→「任用一覧（様式）で書き出す」で、同じ列構成のExcelを作れます（3月の任用一覧の作成に使えます）。

### そのほかのExcel

- 「取込用のひな形をダウンロード」で列見出しの例を確認できます。見出しは多少違っても自動で対応付けます（例：「任期（自）」「任用開始日」「開始日」はどれも任期の開始日として読み込み）。
- 日付は `2026/4/1`、`R8.4.1`、`令和8年4月1日`、Excelの日付セルのいずれも読み込めます。
- 職員は職員番号 → 氏名の順で照合します。任用・評価の取込時、台帳にない職員は自動追加できます。
- 同じ職員・同じ任期の任用は重複登録されません。評価は同じ職員・同じ年度なら上書きします。
